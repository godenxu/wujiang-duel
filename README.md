    - **城池归属与边境大战（野战→攻城两段式）**：城池归属独立于武将分布的固有阵营，可随战事易主；对马岛作为唯一连通两大板块的海路中转站（中原侧经建业、徐州两港，战国侧经萨摩、肥后两港，各两条航线），初始划归战国一方。每逢天下历**月末**（第 30/60/90…天宿营时），会爆发一场**月末国战**——**只打跨国边境**（两端势力分属中日两国），是两国间的定期大会战；**同国势力之间的兼并**则由你随时可发起的「⚔️ 出征」与各势力的日常行动承担（详见「势力与身份」），两套战事各司其职、不再撞车。是否亲历改为**自选出战**：开战前弹出可勾选的出战名单，但只有**主角本人与你麾下的班底**（仕官期为「团队」，自立当主后即「本势力武将」）才需要玩家逐一勾选决定是否出战——其余"仅仅现身过、尚未收编入队"的武将与你的选择无关，一律由候选池自动抽点补满（未被勾选的队友则完全不派，不会像普通武将那样仍有概率被随机抽中）。开战前还有一道**出阵比例滑杆**（10%~100%，默认 60%）：出阵兵力从你所在这座边境城池的**驻军**中调拨（详见下方「城池兵力」），出得越多这场仗越经打，但家底也空得越多——己方按滑杆比例、敌方固定调拨七成，未出阵的那部分留守本城。
      这场冲突分**两段**：先是一场**野战**决出谁能打到对方城下——一律以野战演武方式开打，勾选主角亲历时是完整的排兵布阵→阵前斗将→挥军破阵（阵形相克、地形、军令等策略维度悉数登场，兵力多寡只影响战线能扛多久、不影响每一击的力道），未勾选主角则**全自动推演**、倍速直接跑完。野战得胜一方随即化身攻方，率野战幸存之军乘胜杀奔败方城下，打第二段的**攻城战**——守方由目标城池当前已现身的武将（含委任的守将）加上该城**尚未出征的留守驻军**组成，若目标城一兵一将俱无则直接开城、无需再打一场；否则复用同一套野战演武引擎再打一场，胜负才真正决定城池是否易主。主角只有在**野战亲历且获胜、本人幸存**时才会随军继续亲征攻城，否则（含野战即落败）攻城战全程自动推演。胜方直接夺取败方该城，**战败一方原驻守该城的武将会退守至己方相邻城池，胜利一方也会随机挑选若干已现身武将进驻新占领的城池**，前线因而随城池易主与部署调整逐月推移；**兵力同样按最终战果分流**——攻方此役幸存的兵力就地成为新占城池的驻军，若攻城未克则撤回己方出征的那座城池，守方战后余兵（无论城池是否失守）就地驻守或随城陷落。
      **城墙的六维守备加成已移交专属攻城战**：只有己方城池被围攻时，守军才享有城墙等级对应的加成（另有驻军上限加成不受影响，平时野战不再叠加）。**战果金币只在主角随军攻城时才与你的钱袋相关**：攻克可得所夺城池金币日产出 **30 倍**（约合一月产出）的犒赏、名声 +20；攻城未克则改发一份约合十天产出的**掳掠慰劳金**、名声 +10（不再有任何赔付——败仗最坏也只是拿不到犒赏，不会倒扣）；未随军攻城（含野战即落败、或压根没有勾选自己），城池归属照常见分晓，但胜负不会动你的钱袋分毫。
    - **势力与身份（乱世豪杰志）**：中日两国之下另有 20 家**势力**（每国 10 家，如蜀汉/曹魏/东吴/吕布、织田/武田/上杉/岛津等），各领数座城池、各奉其**主公**；国别（中/日）终身不变，但**城池归属、武将效忠、玩家本人的官身**都以势力为单位，可随战事流转。地图上城池按**所属势力着色**——中原诸势力一律暖色（红/橙/金/褐）、战国诸势力一律冷色（青/蓝/靛/紫），扫一眼色温即知中日，看具体色相才分家门，城池徽章左缘另有 2px 国别竖条作双保险；左下角「🎨 势力」可展开色卡图例。城池面板、全部城市表、武将详情均标注所属势力与主公姓名。
      **武将效忠与忠诚度**：每名武将或归属某势力、或**在野**（约两成开局即为浪人，如「卧龙未出山」的诸葛亮），有势力者各有 0~100 **忠诚度**（分赤诚/忠心/平常/离心/异心五档配色，全武将表可按势力/忠诚排序，一眼找出谁挖得动）。忠诚逐月向一个由「待遇」决定的**软上限**收敛：不做任何笼络者自然停在 55~65，要推到 90 以上必须动用**席位有限**的封赏（见下），故各家势力都天然形成「死忠核心 + 离心外围」的结构，挖墙脚永远有明确的下手处。软上限另受**主公魅力**影响——刘备的部下天生难挖，董卓的部下人心涣散。**友谊与忠诚联动**：同势力同僚交情越厚越死心塌地；他家武将与你越交好，对其主公反而越离心——先结交、再等其离心、最后一举「🗣️ 招揽」（200 金，成功率随友谊/忠诚/名声与对方势力威名浮动），是一条完整的策略链。**主公不可招揽**，要其人只能灭其势力。

  - **友谊与金币**：主角与 400 名武将并肩/交手皆积累友谊（陌生→相识→好友→挚友→生死之交，**上限 300**）；各玩法胜利赚金币；**招募入队须友谊满上限（300）且需支付重金**（招募费 = 武将评分 × 10 金，不再有中间档可招募或免费档）；队友可任 2v2 副将，同阵营队友在组队大战/国战/阵营大战中必上阵；世界杯竞猜得分直接兑换金币；金币便利消费——百人斩机缘 50 金重抽、主角单挑倒地 100 金服「回魂丹」满血续战（每场一次）、国战开局 30 金重掷地图、宝物库鉴宝 50 金；武将图鉴显示与主角的友谊值（可排序）；所有金币收支都会在结算弹窗（与经验同屏）或即时提示中明示金额与余额。**加深友谊**有两种途径：在武将详情页的装备栏为其选择宝物即视为赠送（无需另开弹窗，且史实武将的装备栏没有「卸下」选项、只能以新换旧），增幅按宝物稀有度 +10/+30/+60/+100，同一件宝物只在第一次赠给某位武将时计入友谊——日后无论怎么换装、换回都不会重复计，想再赚友谊需真正获得新的宝物；若目标对应槽位已有装备，旧装备会退回玩家仓库（不会丢失）。或拜访（无需消耗，每人每【游戏日】限一次——宿营过夜后可再访，友谊随机 +1~+2；**友谊达上限 300 后不可再拜访**，按钮置灰）。**切磋习得**：切磋结算时另按对手当前友谊值有 1%~31% 概率触发——若败方六维中最高一项严格大于胜方同一项，胜方该项永久 +1（主角走加点成长、对手走战役内数值，均只在本局生效，均受**六维基础值 110 上限**约束，装备加成不受影响）。所有「友谊 +N」结算文案均按实际生效增量显示——若对方友谊已在上限附近，文案会如实显示较小的实际增量甚至改为「已至上限」提示，不会出现友谊早已封顶仍显示按名义值增长的错位文案。
  - **宝物系统**：五类宝物（各 20 件历史典故命名，共 100 件）——兵器(加武力)/坐骑(加统帅)/书籍(按典籍性质固定加智力或政治)/服饰(加魅力)/奇珍，各分普通/精良/稀有/传说四档稀有度，**每件宝物在对应区间内独立随机取加成值**（普通 +1~+2、精良 +3~+5、稀有 +6~+8、传说 +9~+10），基础售价约为该档基准加成值的 1000 倍（普通 1000 金、精良 3000 金、稀有 6000 金、传说 10000 金）；**奇珍**不止加体力，还固定绑定「暴击率」「气血回复」「护体（残血额外减伤）」「气盛（战意回复加快）」「行动力上限」等六种效果之一，真实影响战斗结算或天下游历；其中「传国玉玺」「九鼎」两件奇珍**仅当生成为传说品阶时**才切换为行动力上限效果（佩戴即 +1，不随稀有度浮动，二者功能相同、仅需其一，奇珍槽位唯一故无法叠加），其余品阶（普通/精良/稀有）仍是各自原有的常规效果（暴击率/护体）按稀有度正常浮动；「赤兔·千里神驹」「千里靴」两件全地图各仅一件的唯一奇珍则是纯粹的高稀有度专属装备，不附带行动力效果。历练/2v2、车轮大战、百人斩、阵营大战、组队大战、国战、世界杯获胜均有概率掉落宝物或材料（一统天下、世界杯夺冠额外必得高稀有度宝物）；**战场拾获的宝物为「未鉴定」状态，不揭示具体细节，需在「宝物库」花 50 金鉴宝后才能查看真身、装备或拆解**；养成主页「宝物库」——仓库浏览/鉴宝，已鉴定且未装备的宝物卡片底部并列「拆解」与「出售」两个各占 50% 宽度的按钮（均需二次确认）：**拆解**换取对应材料，**出售**以低于市价的价格（市价 50%）换取金币，售出的宝物会以自身名称/属性重新回流「商店」页签的货架池，可被再次购回；**跨城宝物贸易**——各城「集市」分「🛒 买入」「🚢 卖出」两个页签（各自按价格从高到低排列，弹窗尽量占满可视高度、减少上下滚动）：买入即固定的每日随机货摊；卖出则是把随身宝物就地贩卖给本地行商，售价按**当前所在城市的真实行情**结算（约市价的 85%，明显高于仓库固定五折的「出售」），但同城买卖必然亏本，唯有异地低价买入、跑一趟高价城池贩卖才能吃到差价，移动耗行动力天然限制了套利频率，理论极限毛利约一成出头；卖出页顶部还有「一键卖出非传奇宝物」按钮（标注件数与合计估价，点击需二次确认），一次清空非传奇的零散宝物，传奇级宝物不在批量范围内，须逐件贩卖且同样弹窗二次确认，避免手滑卖掉贵重之物；图鉴收集进度（含各类型/各奇珍效果的属性加成区间）、每日商店购买（购买即鉴定）/花金重刷、消耗材料+金币锻造（连续 12 次未出稀有以上下一次保底，锻造品同样即得即鉴定）；首页「宝物阁」则是不受进度影响的全局总览，一次性展示全部 100 件、可编辑属性/加成（限幅 ≤15）、可自建。**400 名史实武将均可持有并穿戴宝物**——不只是队友，任意武将的详情弹窗在六维数据正下方都有一排紧凑的五槽装备栏（点击即可装备/更换，取消会回到详情页而非直接关闭）；主角的装备则在角色扮演主页管理（可自由卸下）；加成会实时计入该武将出战的任何玩法（历练/车轮/百人斩/2v2/阵营/组队/国战/世界杯），角色扮演主页、武将详情页、乃至战斗界面点头像弹出的信息里，六维数值旁都会正确标注装备带来的加成；武将图鉴列表中，任何已装备宝物的武将都会显示其携带的宝物图标（全局图鉴视图除外，不显示进度数据）。
- **多种打法**：猛攻 / 普攻 / 格挡 / 谋攻 / 束缚 / 弱化 / 疗伤 / 蓄力，采用「相克 + 属性 + 随机」结算模型，**体力归零即 KO**；蓄力成败取决于己方武力/智力中较高者，暴发倍率按后续招式区分（谋攻无视格挡、暴发倍率略低于可被格挡卸力的猛攻/普攻，力求两条爆发路线收益相当）；疗伤成败取决于魅力、回复量取决于政治。完整数值公式见 [BALANCE.md](BALANCE.md)。
- **美术与音效**：水墨国风界面、雷达图属性、伤害飘字、命中震屏；**纯 Web Audio 程序化生成**的五声音阶背景音乐与战斗音效（无需任何外部音频文件）。
- **PWA**：含 `manifest.json` + `sw.js`，可「添加到主屏幕」安装为 App，离线可玩。

## 🚀 运行

任意静态服务器即可（PWA 需 http/https，不能用 `file://` 直接打开）：

```bash
# 方式一：Node http-server
npx http-server -p 8099 -c-1

# 方式二：Python
python -m http.server 8099
```

浏览器打开 `http://localhost:8099`。

## 📱 安装到手机

1. 将整个文件夹部署到任意 HTTPS 静态托管（GitHub Pages / Vercel / Netlify 等）。
2. 手机浏览器打开网址 → 菜单选择「添加到主屏幕 / 安装应用」。
3. 之后可像原生 App 一样离线启动。

## ➕ 丰富武将数据

两种方式：

1. **游戏内**：进入「武将图鉴」→「新增武将」，填写属性即可，自动持久化。
2. **改源码**：编辑 `data/generals.js`，在 `CN_GENERALS` 或 `JP_GENERALS` 数组追加：

```js
{ name: "某某", title: "称号", intro: "简介…",
  ti: 90, wu: 88, tong: 80, zhi: 70, zheng: 60, mei: 75 }
```

`side` 与 `id` 会自动补全。`ti`（体力）同时作为单挑初始 HP。

> 注：游戏内一旦改过数据库会以 `localStorage` 为准；想用源码新增项，可在图鉴页点「恢复默认」刷新。
